# 0004 Heading

Status: done

Goal: ATX (`# x`) and setext (`x` over `===`/`---`) headings render as
styled preview lines (`DocPreviewH1..H6`), and the project has its first
reference pairs (own inputs, expected output generated by `cmark`).

rules (with tab-expanded indent); `core/highlight.lua` and span

projection (`doc/plan.md` per-component workflow); `doc/references.md`,
`LICENSE`, `NOTICE`.

`tests/{unit,golden,integration,pairs}/`, `tools/oracle/`, `Makefile`,

Decisions taken for this slice:

* Pair expectations: own inputs, `cmark` output (`cmark --to html`),
  provenance in `.meta` (tool, version, command). No CommonMark spec text
  or examples committed. Recorded in `doc/testing.md` 2 and
  `doc/references.md` (task 1).
* Pair skip manifest is a Lua table file `tests/pairs/<fmt>/skip.lua`
  (`{ ["<case>"] = "reason" }`), not TOML: tests are Lua and TOML would
  need a parser. `doc/testing.md` 2 is updated (task 1).
* Heading inlines are plain `text` until 0006; pairs whose expectation
  needs emphasis, escapes or entities are skipped with reason
  `inline: 0006`/`escapes: 0006`.
* Span columns are 0-based byte offsets, end exclusive (what
  `nvim_buf_set_extmark` wants); lines 1-based in `Output`.
