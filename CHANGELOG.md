## [0.1.0] - 2026-11-15

### Added

- Markdown preview in a read-only split: headings, emphasis, links, block
  quotes, lists, code, HTML blocks, tables, images (placeholder),
  footnotes, thematic breaks.
- Mermaid diagrams drawn as text: flowchart, sequence, class, state, ER,
  pie, gantt; standalone `.mmd` / `.mermaid` files.
- Async, cancellable rendering; resize re-wrap; cursor and scroll sync;
  large-file guard; `vsplit`, `hsplit` and `replace` layouts; config
  validation.
- `:DocPreview` command, `:checkhealth doc_preview`, `:help doc_preview`.
